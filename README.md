# Project_2

🔢 C++ Math Quiz Game 🎮
A fun and simple math quiz game developed in C++. Choose your level and operations to test your skills! 🚀

Features:
Difficulty Levels: Easy 🟢, Medium 🟡, Hard 🔴, or Mix 🔄.

Operations: Add ➕, Sub ➖, Mult ✖️, Div ➗, or Mix 🎲.

Instant Feedback: Get immediate results for each question ✅❌.

How to Play:
Start the game.

Select your number of questions (1-10) and preferences.

Answer the questions and check your final score! 🎉
